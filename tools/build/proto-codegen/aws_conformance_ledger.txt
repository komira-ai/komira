# The AWS protocol conformance ledger.
#
# One row per (protocol, direction) the conformance driver drives, over
# botocore's protocol conformance corpus as the pinned botocore archive holds
# it (//third_party/botocore:protocol_tests):
#
#   <protocol> <direction> <total> <pass> <upstream_skip> refused[<name>=<n>,...]
#
#   protocol       a suite's `metadata.protocol`.
#   total          the cases of that protocol and direction in the corpus.
#   pass           cases the generated code answers exactly as expected.
#   upstream_skip  cases botocore's own protocol-tests-ignore-list.json
#                  skips. It must equal the count derived from that file
#                  (CorpusDrift otherwise).
#   refused        cases whose client the generator refuses to emit, per
#                  refusal name (generation fails with `REFUSED <name>:`).
#
# Every case is exactly one of the three, so the counts add up to total.
# There is no column for a failing case: one is red, and so is any of
#   a total or upstream_skip that differs from the corpus (CorpusDrift);
#   fewer passes than recorded (Regression);
#   a refusal that grew, or a new refusal name (RefusalGrew);
#   a refusal that shrank (Stale when no case in the row is red,
#     RefusalVanished when one is);
#   a row the run does not produce, or a missing one (ExtraRow, MissingRow).
#
# Checked by //tools/build/proto-codegen:aws_conformance_test, which
# aws-client-gen is published behind.
