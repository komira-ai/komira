# Coverage census

Generated: `./buck2 build //:coverage_census` renders this file from each
package's coverage_census.tsv, the numbers of a coverage build of each
library under `src/`, and each package's coverage_held, the metrics it
holds at the 99.00% target. The same build fails while a package the census
measured at the target does not hold it. This file is not committed;
tools/build/coverage/census.md says how to refresh
them and what a hold does: a library under the target on a metric its
package holds fails its coverage gate in every mode, so its conda package
is not built; below the target and not held, it fails nothing.

`-c komira.coverage=true`: line coverage from kcov over every test of the
library, branch coverage from the branch records of the libraries in
`COVERAGE_BRANCH_GATE` (tools/build/coverage/policy.bzl); the others show
*not gated*. The libraries under `src/tests/` are test code, outside the
target: they are listed for information at the end, held to nothing.
