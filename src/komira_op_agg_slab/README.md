# komira_op_agg_slab

The struct-state hash aggregation table: `SlabStorage`, a hash table of groups keyed by a packed composite key (one to eight fixed-width columns, Int64 by default) that probes sixteen 1-byte fingerprints per SIMD compare, with one columnar state slab per aggregate. Each slab is read as its aggregate's `komira_op_agg_state.AggregatorWithStruct` state struct (Welford, bivariate Welford, median buffer, largest-k), so the aggregates fold in place: `init_state_with_struct` on a new group, `commit_aggregator_with_struct` (and `commit_corr_aggregator_with_struct` for the two-input CORR) per batch, `combine_donor_keys_with_struct` to merge one worker's table into another with one probe per donor group, and `finalize_aggregator_with_struct` plus the `finalize_keys_*` methods to emit the result in group order. Keys and outputs are passed as spans whose lengths are checked; no public method takes a pointer.
