# komira_op_agg_hash

The hash aggregation tables of the engine: `FlatHashAggregator`, a split-index table (a compact tag array to probe, a slot directory, and an insertion-order entry buffer of hash, Int64 keys and accumulator slots laid out by an `AggLayout`); `PerfectHashAggregator`, a flat array for small dense integer key domains (at most 65,536 keys); `PartitionedFlatHashAggregator`, one `FlatHashAggregator` per radix partition; `FlatHashPartitionFlush`, the per-partition row buffers a table scatters into when it reaches its cache-resident cap; and `AggCommitPlan`, which folds a record batch's value columns into the accumulator slots of any of these tables, per row (`commit_row`, `commit_row_ph`) or loop-transposed per batch (`commit_batch`, `commit_batch_partitioned`, `commit_batch_indexed`). Batches of keys, rows and handles are passed as spans; no public function takes a pointer. The row kernels are `komira_op_agg_state`'s; the sinks that drive these tables are in the packages above.
