UnsupportedOperation: bind: SQL not supported: the `||` string-concatenation operator. DuckDB's `||` PROPAGATES NULL (`'a' || NULL` is NULL) where this engine's only concatenation, `concat()`, SKIPS a NULL operand (`concat('a', NULL)` is 'a'), and answering one for the other would be wrong on every row with a NULL. The missing primitive is a STRING-typed NULL value in the plan (the CASE that would propagate the NULL has no string NULL to return). `concat(a, b)` is served for the NULL-skipping answer, and is EXACT wherever neither operand can be NULL.
