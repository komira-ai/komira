# The UDF runtime conformance corpus

Status: proposed, not built. This is the case list of the shared conformance corpus that [the UDF runtime interface](udf_runtime_interface.md) defines in its §6.3: what each case runs, the defect it catches, and the planted mutant that proves it can fail. Section numbers (§x.y) refer to `udf_runtime_interface.md`; `§10.1` to `§10.9` refer to `optimized_plan_udfs.md` and `§10.10` to `§10.14` to `optimized_plan_udf_runtime.md`, as there.

## Shared cases

Every runtime runs these, through the C ABI. A case marked "(plan case)" runs through lowering and the engine's UDF operators (stage S6); the others drive the C table directly.

| Case | Defect caught | Planted mutant |
|---|---|---|
| Scalar over a batch with nulls, `PROPAGATE`; nested null children | The runtime is called for null rows | The host skips null compaction |
| `MAP_BATCHES_COLUMN` returns one row short | The length check is missing | Remove the length post-condition |
| A float function returns int64 | An unsafe cast is accepted | Cast float to int64 silently |
| A runtime returns the wrong `n_buffers`, or offsets past the data | The engine reads out of bounds | Skip import validation |
| Empty batch; empty group; an aggregate with no keys over empty input | Off-by-one on empty input | Skip the call on zero rows |
| Sliced input with an offset that is not a multiple of 8 | A reader ignores `offset` | Echo ignores the bit offset |
| Zero-argument scalar over 5 rows | The row count is lost | Take the length from the first child |
| `raise_on_row(3)` under `CASE WHEN` that never selects row 3 (plan case) | Eager evaluation of a branch | Evaluate both branches |
| The same input split 1×N and N×1 across two instances | A result depends on the instance or the split | An instance-local row counter |
| Mergeable `sum`, split `PARTIAL`/`FINAL` across two instances | A merge that is not associative; lost state | `agg_merge` overwrites instead of adding |
| 100 000 groups of one row, mergeable and plain | One crossing per group | A host that calls once per group (the case asserts crossings ≤ batches + pulls) |
| A frame generator yields before reading all its input; yields three tables, then raises | A borrowed input stream; lost batches; the wrong error row | Drain all input before the first output; buffer all output |
| `raise` on row 3 of 8 | An error code without a message; the wrong row | Return `ERR_RAISED` with a NULL message |
| Every array is released exactly once, including `args` on an error path | A leak or a double release | Count release callbacks; release `args` in both the runtime and the host on error |
| A UDF holds a view of every input batch, including a frame that holds its inputs while nested calls run on its context | Input that must outlive the call is released early, or a runtime that runs user code elsewhere stalls when its buffers fill | Release `args` at return regardless of views; no copy-out when the slot-heap bound is reached |
| Cancel flag set during a long call; a context that must be replaced | Cancel is ignored; a lost context is reused | Ignore the flag; reuse the context after `ERR_INSTANCE_LOST`. The case asserts that the run fails, the context is closed, and no further call reaches it |
| A fixture that ignores the cancel flag and spins (runtimes with `FORCED_STOP`) | A stopped call reported as a crash, or never ending; the dead context is reused | The runtime returns `ERR_INSTANCE_LOST` or `ERR_WORKER_CRASHED` for a forced stop, or never stops. The case asserts `ERR_KILLED`, the run's cancel, `ERR_INSTANCE_LOST` from a later call on that context, and a successful close |
| The same with a deadline instead of a cancel | A deadline reported as a cancel | The host maps every `ERR_KILLED` to the run's cancel. The case asserts `UDF_DEADLINE_EXCEEDED` |
| A `call_batch` whose worker calls `abort()` mid-batch, and one whose worker exits with status 0 mid-batch (runtimes with `CONTAINS_CRASHES`) | A crash retried, or reported without the UDF or the signal | The host retries the batch. The case asserts `UDF_WORKER_CRASHED` naming the UDF and the signal or exit status, and one run of user code |
| A frame whose worker crashes in `frame_next` (runtimes with `CONTAINS_CRASHES`) | A broken frame treated as finished | The host closes the frame and continues. The case asserts `UDF_WORKER_CRASHED` naming the frame UDF and the signal |
| A mergeable aggregate whose worker crashes in `agg_update` on batch 3 of 5 (runtimes with `CONTAINS_CRASHES`) | An aggregate continued with lost state | The host opens the aggregate again on a new context. The case asserts `UDF_WORKER_CRASHED` naming the aggregate UDF and the signal |
| `agg_open` returning `ERR_INSTANCE_LOST` (an echo setting) | A failed open treated as harmless | The host opens the aggregate again. The case asserts `UDF_WORKER_CRASHED` naming the aggregate UDF |
| A `VOLATILE` fixture that counts its runs in a file, whose worker crashes after the count (runtimes with `CONTAINS_CRASHES`) | A `VOLATILE` batch run twice | The host retries the batch. The case asserts a count of at most one per batch |
| A `VOLATILE` fixture that counts its runs and raises on row 3 | A `VOLATILE` batch bisected, so user code runs it twice | The host bisects `VOLATILE` batches. The case asserts `UDF_RAISED` and a count of one |
| A non-`VOLATILE` `MAP_BATCHES_COLUMN` that raises with `row` -1 when its batch contains row 5 of 8, and reports the row when given a half | Bisection that finds the wrong row, or none | No bisection; a split that drops the middle row; the half's row offset not added. The case asserts `UDF_RAISED` naming row 5 |
| A frame whose `in` pull runs a scalar `call_batch` of the same runtime on the same context, the scalar both plain and `async` (nested call; echo's setting, then each managed runtime and `komira/native` with the `native-c` and `native-mojo` fixtures) | A runtime that cannot serve the one allowed nesting | The runtime refuses the nested call, or deadlocks; the harness times out and goes red. The case asserts the frame's correct output |
| Two levels: a frame over a frame over a scalar, all on one context | Nesting that works one level deep only | The runtime serves one nested call at a time. The case asserts the outer frame's correct output |
| Two levels, `F1` over `F2` over scalar `S` on one context, and `S`'s worker crashes (runtimes with `CONTAINS_CRASHES`) | An object closed while a call on its context is still in progress, or two run errors | The host closes the context when `F2` returns. The case asserts `UDF_WORKER_CRASHED` naming `S`, `EIO` to `F2`'s pull and then `F1`'s, `F2` then `F1` closed, both after `F1` returns, then the context |
| A nested scalar raises while the frame waits on its pull | The run error names the frame, or the frame's own status wins | The host reports the waiting frame's status. The case asserts `UDF_RAISED` naming the scalar UDF, `get_next` returning `EIO` with the scalar's message, and the frame closed |
| A nested scalar's worker crashes while the frame waits (runtimes with `CONTAINS_CRASHES`) | Objects closed before the waiting call returns, or the context left open | The host closes the context before `frame_next` returns. The case asserts `UDF_WORKER_CRASHED` naming the scalar UDF, then the frame closed after `frame_next` returned, then the context |
| A frame whose `in` pull the harness holds past the frame's deadline, with no nested call; the fixture records whether user code received the batch (runtimes with `FORCED_STOP`) | A waiting call stopped by force, or a late batch run | The runtime stops the frame by force during the pull; the runtime hands the batch to user code. The case asserts no `ERR_KILLED` during the wait, `ERR_DEADLINE` once the pull returns, and that user code never received the batch |
| The run is cancelled while a frame's pull is held, with no nested call | A cancelled run left waiting, or stopped by force | The runtime stops the frame by force. The case asserts `EIO` to the pull, no `ERR_KILLED`, the frame closed, and the run's cancel as the run error |
| A waiting frame in echo whose input comes from a `komira/native` scalar that fails (cross-runtime) | A failure in another runtime handled differently from a nested one | The host reports the waiting frame's status. The case asserts the scalar's run error, naming it, `EIO` to the echo frame's pull, and the frame closed after it returns |
| A Python frame annotated with fields `{a}`, grouped by `k` | Every annotated grouped frame refused at admission, or at `load` | Capture keeps the annotation's fields only; `load` compares the annotation against all recorded fields. The case asserts read set `{a, k}`, recorded annotation fields `{a}` and key fields `{k}`, and `validate` and `load` OK |
| A native grouped-frame library built for `{a, k}`, grouped by `k`; then one built for `{a}` | A native grouped frame refused although its fields are right, or accepted without its key | Capture adds `k` to the native descriptor, which `load` then refuses (`ERR_LOAD`). The case asserts `validate` and `load` OK for `{a, k}`, and `ERR_READ_SET_MISMATCH` naming `k` at admission for `{a}` |
| A fixture that allocates past its process's memory cap (runtimes with `CONTAINS_CRASHES`) | A memory stop reported as a crash | The runtime reports every exit as a crash. The case asserts `ERR_OUT_OF_MEMORY` and no retry |
| The host breaks a rule the runtime can see: an `args` struct with one child more than the bound schema; an argument struct with a non-zero offset | A host defect blamed on the runtime or on user code | The runtime returns `ERR_INTERNAL`; the error table maps `ERR_HOST_CONTRACT` to `UDF_RUNTIME_FAULT`. The case asserts `UDF_HOST_CONTRACT_VIOLATION` and no retry |
| Two contexts in parallel | Mutable state shared across contexts | A global accumulator in the runtime |
| Node with external buffers disallowed | No copy fallback | Always create external buffers |
| A descriptor with a trailing unknown field; non-canonical bytes; a newer `descriptor_version`; a `RecordedFields` with unsorted `fields`, unsorted `key_fields`, a repeated name, or a key also in `fields` | The validator is too lax | `validate` always returns OK. The case asserts `ERR_DESCRIPTOR` for each |
| A spec whose `arg_types` or `return_type` differ from the descriptor's signature; a shape the descriptor does not list; a descriptor entry other than `code.entry` | `validate` accepts declared types the function was not captured with | `validate` checks only the descriptor's encoding. The case asserts `ERR_DESCRIPTOR` naming the field and both types, and `ERR_DESCRIPTOR` naming the shape |
| `validate` with `code_root` pointing at an empty directory, then at code objects whose constructor or top-level code writes a marker file | `validate` opens the code, so admission runs user code or library constructors | `validate` loads the code to read the signature. The case asserts OK and no marker |
| Code that disagrees with its descriptor: a native library whose export table gives another signature; a Python entry whose hints differ from the recorded ones | The descriptor is trusted and the code is never checked | `load` skips the comparison. The case asserts `ERR_LOAD` |
| A `STEP` returning a table with no columns | An empty table is mistaken for an error | Treat zero columns as failure |
| Round trip of every type in the runtime's mapping table | A silent loss beyond the stated ones | Truncate microseconds in Python |
| `ROW` with a conditionally read field: `f(r) = r.a if r.flag else r.b`, read set `{a, flag}` (a `columns=[...]` the user made too short), over a batch where row 3 has `flag` false | An undeclared read returns null or a wrong value | The row proxy returns null for an unknown name. The case asserts `ERR_FIELD_NOT_DECLARED` with `row` 3, naming `b` |
| The same case with the read set `{a, b, flag}` (the scan, or `columns=[...]`), and with `read_set` unset | A correct read set, or the absence of one, still fails | The proxy checks names against the input schema instead of the columns passed; a runtime that treats unset as empty fails every read |
| `ROW` whose function catches the language's exception around the undeclared read | A caught violation passes silently | `call_batch` reports only uncaught errors |
| `ROW` reading 2 fields of a 100-column scan (plan case) | The row UDF keeps every column live | Lowering passes the whole input row; the case asserts the scan's projection and the `args` children equal the read set |
| `ROW` and `MAP_BATCHES_FRAME` with `read_set` unset over a 5-column scan (plan case) | Unset read as "no columns" | A planner that maps unset to an empty projection; the case asserts all 5 columns reach `args`, in input order |
| `MAP_BATCHES_FRAME` with read set `{a}` over a 100-column scan ungrouped, and with read set `{a, k}` and `group_by k` (plan case) | A frame's read set ignored, or its key pruned | Pushdown stops at the frame node; a planner that prunes `k`. The case asserts the scan's projection is `{a}`, then `{a, k}`, and that the frame's batches hold the group ordinal (grouped) followed by exactly the read set |
| Plan validation: a grouped frame with read set `{a}` and `group_by k` | A key column the returned tables need is pruned | Drop the check. The case asserts `OPTIMIZED_UDF_READ_SET_GROUP_KEY` naming `k` |
| Plan validation: a frame with `read_set` unset whose child output differs from `arg_types` in a name, a type or the order | A frame bound to one schema receives another | Compare names only. The case asserts `OPTIMIZED_UDF_ARGUMENT_TYPE_MISMATCH` for each of the three |
| `MAP_BATCHES_FRAME` with `read_set {}` returning each batch's row count (plan case) | An empty set read as unset, or a lost row count | A planner that keeps every column for an empty set; a host that takes the length from the first child. The case asserts a zero-column projection and the right counts |
| ABI: a `ROW` spec with no `args` children over 5 rows, and a frame whose input batches have no children and lengths 2, 2 and 1 | The row count is lost with the columns, or a zero-column batch is dropped | Take the length from the first child; skip batches with no columns. The case asserts 5 results and three input batches of lengths 2, 2, 1 |
| Plan validation: a `read_set` on a `SCALAR`, `MAP_BATCHES_COLUMN`, `AGGREGATE` or `STEP` `UdfRef`; a `read_set` not sorted by UTF-8 bytes or with a repeated name; `arg_types` that disagree with it; a frame child that lacks a read-set name; a `ROW` over an input with two columns of one name | A bad read set reaches the host | Drop each check. The case asserts `OPTIMIZED_UDF_READ_SET_KIND`, `OPTIMIZED_UDF_READ_SET_INVALID`, `OPTIMIZED_UDF_READ_SET_ARG_MISMATCH`, `OPTIMIZED_UDF_READ_SET_COLUMN_UNKNOWN`, then `OPTIMIZED_UDF_READ_SET_INVALID` naming the name |
| Canonical encoding: one `UdfRef` with `read_set` unset and one with it set and empty | Unset and empty share a digest | An encoder that omits an empty message. The case asserts two different digests |
| Producer: `f(r) = r.a if r.flag else r.b` with no declaration, captured after a local run where `flag` was always true | The read set misses a field on an untaken branch | The scan follows only the branch the local run took; the read set is taken from the local run. The case asserts `{a, b, flag}` |
| Producer: a `ROW` function annotated with a `TypedDict` of fields `a` and `b`, and a frame function whose input parameter is annotated with a dataclass of fields `a` and `b` | An annotation ignored | The SDK reads only `columns=`. The case asserts read set `{a, b}` for each |
| Producer: a function that iterates its row, converts it to a dict, or passes it to another function; a frame function the SDK cannot scan | A guessed read set too small, or "every column" listed | The scan ignores whole-row operations; the SDK lists every input column. The case asserts `read_set` unset |
| Producer: a branch that reads a literal field the input lacks; `getattr(r, name)` with a computed name; `columns=` with a repeated name; `columns=` that disagrees with the annotation; a `ROW` function of two parameters; a grouped frame scanned without its key | A bad read set reaches the plan, or a valid function is refused | Drop each refusal; refuse computed names; omit the key. The case asserts `UDF_READ_SET_COLUMN_UNKNOWN`, `read_set` unset, `UDF_READ_SET_INVALID` (twice), `UDF_ROW_SIGNATURE`, and a read set containing the key |

## Cases per class

The harness takes the class and the features from `describe` (§4.2) and runs these in addition to the shared cases. The cases marked **launch gate** must pass before native UDFs ship (§1.2).

| Class | Case | Defect caught | Planted mutant |
|---|---|---|---|
| native | A library whose bytes differ from their sha256 | Unverified machine code is loaded | `load` calls `dlopen` before it checks the digest |
| native | A spec with libraries only for another platform | A wrong-platform library is loaded, or the refusal comes mid-run | `validate` accepts any platform and `load` picks the first library |
| native, **launch gate** | Two fixture libraries that both define the same internal symbol, loaded in one process, each calling its own | One user library interposes on another, or on the engine | Load with `RTLD_GLOBAL` |
| native | A library that exports `komira_udf_runtime_init_v1` instead of `komira_udf_native_init_v1`, or a second symbol | A runtime and a user library are confused | Resolve either symbol |
| native | A fixture that raises on row 3: a Mojo function declared `raises`, behind the Mojo export helper (S3b); a C++ fixture that throws and a Rust fixture that panics, behind their helpers (S3c) | An error escaping the export helper: unwinding across the ABI, or a Mojo error with no `ERR_RAISED` | An export helper without the catch |
| native | A library whose `describe` reports `MANAGED`, another `runtime_id`, or lacks the spec's shape | The host loads a library it cannot drive | `load` forwards without checking the library's capabilities |
| native | A `ROW` library built against fields `{a, b}`, referenced by a `UdfRef` with `read_set` `{a}`, then `{a, b, c}`, then `{a, b}` with `b` of another type; a library built against an empty field list `{}` referenced with `read_set` `{}`, then `{a}`; an entry whose descriptor has no field list | A library bound to fields the plan does not pass, or types it does not expect | `validate` skips the field check for native libraries. The case asserts `ERR_READ_SET_MISMATCH` (`OPTIMIZED_UDF_READ_SET_DESCRIPTOR_MISMATCH`) twice, then `ERR_DESCRIPTOR`, success with `{a, b}`, success for `{}` with `{}` and `ERR_READ_SET_MISMATCH` for `{}` with `{a}`, and `ERR_DESCRIPTOR` for the absent list |
| native | Two Mojo fixture libraries loaded in one process, called from several engine threads | The Mojo runtime library cannot be shared in one process | None: it tests an assumption (§1.2), not host code. Red means Mojo has no mode at the first release (§1.3 item 1) |
| native, **launch gate** | A fixture that dereferences NULL in-process | A native fault leaves the run unnamed, commits partial output, or leaves the host unusable | The supervisor reports a generic engine failure; the run's output is committed before the engine exits. The case asserts a named UDF fault naming the library, no committed output, and a next run on the host that succeeds |
| native, **launch gate** | In-process, a fixture that looks for the supervisor's run token: its environment and arguments, `/proc/<supervisor pid>/environ`, `cmdline` and `mem`, files the engine's user id can read, every inherited descriptor, and the supervisor's listening sockets, abstract-namespace ones included (they bypass file permissions); then `ptrace` and a signal to the supervisor | The token, or the supervisor, is reachable from the engine, so code in the engine could report on the run | The supervisor passes the token to the engine in an environment variable or on its own command line; the supervisor and the engine share one user id; the supervisor accepts a liveness message from the engine |
| native | Parallelism in-process: N engine threads (N ≥ 4, each on a reserved core) each call a fixture that spins on the CPU for 200 ms; the harness compares the process's CPU time with the wall time | A lock shared across engine threads in the loader or the library. The case requires CPU time ≥ 0.75 × N × wall time; under one lock it is about 1 × wall time | Echo with the process-wide mutex; `komira/native` taking one mutex around every forwarded call |
| managed | Parallelism: N engine threads (N ≥ 4) each call a spinning fixture through N contexts | One interpreter serving every context | The runtime serves every context from one worker. The case asserts CPU time ≥ 0.75 × N × wall time, summed over the runtime's processes |
| managed | Two contexts in parallel, each with a cached model | State shared across contexts | One interpreter, or one UDF state, shared by all contexts |
| managed | Runtime shutdown with arrays still held by the host | A release that needs the interpreter after it is gone | Finalize the interpreter before draining the release queues |
| plan case | A mergeable aggregate whose state for one group grows to 64 MiB, then one byte past it | The fixed cap is not enforced, is off by one, or is read from the plan | Accept a state equal to the cap plus one byte; take the cap from `max_state_bytes`. The case asserts `UDF_STATE_TOO_LARGE` naming the group key and the 64 MiB cap, and success at exactly 64 MiB |
