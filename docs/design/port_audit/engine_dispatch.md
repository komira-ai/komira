## Gaps

- **Joins and cross/scalar broadcast** (task `pysdk-engine-join-inner`). Earlier files: komira_engine_dispatch/join_node_exec.mojo, komira_engine_dispatch/materialize_join.mojo, komira_engine_dispatch/hash_build_sink.mojo, komira_engine_dispatch/materialize_typed_join.mojo, komira_engine_dispatch/materialize_parquet_typed_join.mojo, komira_engine_dispatch/join_deferred_assemble.mojo, komira_engine_dispatch/join_deferred_kernels.mojo, komira_engine_dispatch/join_deferred_order.mojo, komira_engine_dispatch/fused_dim_build.mojo, komira_engine_dispatch/cross_join_node_exec.mojo, komira_engine_dispatch/cross_frame_resolver.mojo. Missing: Build and probe segments (inner, left/right/full, semi, anti, mark, cross, multi-key) lowered and run; no join SINK_HASH_BUILD or probe operator in real_builder, and lowering refuses joins. Closest code: src/op_join_build, src/op_join_probe, src/op_join_sinks, src/join_assembly. Why: Most TPC-H queries (q2-q5, q7-q22) and any DataFrame merge need joins.
- **Subqueries, union, CTE composition** (task `pysdk-engine-scalar-subquery`). Earlier files: komira_engine_dispatch/decorrelated_node_exec.mojo, komira_engine_dispatch/materialize_subplan.mojo, komira_engine_dispatch/breaker_compose.mojo. Missing: Execute decorrelated semi/anti/mark/scalar-broadcast plans, UNION, shared CTE results and breakers stacked on breakers. Optimizer passes exist (src/optimizer/scalar_subquery_decorrelate.mojo); no executor consumes their output; scalar subquery and union nodes are refused. Why: TPC-H q2, q11, q15, q17, q20, q21, q22 and SQL breadth (union, CTE, subqueries).
- **Top-N and window** (task `pysdk-engine-distinct`). Earlier files: komira_engine_dispatch/materialize_topn.mojo, komira_engine_dispatch/materialize_partition_by.mojo, komira_engine_dispatch/partition_topn_frame_resolver.mojo, komira_engine_dispatch/partition_topn_node_exec.mojo. Missing: per-partition top-K (ORDER BY with LIMIT is cut as SINK_TOPN). Closest: src/op_window. Why: Basic SQL breadth and DataFrame nlargest. SELECT DISTINCT is served by src/lowering/cut_distinct.mojo; window functions by src/lowering/cut_window.mojo and src/pipeline_exec/sink_window.mojo.
- **Extended aggregates** (task `pysdk-engine-distinct`). Earlier files: komira_engine_dispatch/agg_extended_fold.mojo, komira_engine_dispatch/agg_mixed_split.mojo, komira_engine_dispatch/materialize_cd_prededup.mojo. Missing: the mixed-aggregate split and prededup fast route, string MIN/MAX, median, largest-k, corr. COUNT(DISTINCT x), scalar and grouped and beside plain aggregates, is served by src/pipeline_exec/count_distinct.mojo. Closest: src/dispatch_agg_folds, src/op_agg_distinct, src/op_agg_state/statistical_accumulators.mojo. Why: TPC-H q21 area, and common DataFrame median, corr.
- **Aggregate and sort type breadth** (task `pysdk-engine-group-keys-date-decimal-bool`). Earlier files: komira_engine_dispatch/agg_node_exec.mojo, komira_engine_dispatch/agg_scalar_fold.mojo, komira_engine_dispatch/agg_frame_resolver.mojo, komira_engine_dispatch/agg_frame_scalar.mojo, komira_engine_dispatch/materialize_sort.mojo. Missing: group keys of mixed multi-column types are served by the COMPOSITE row, as are single date, decimal and bool keys (a column of another type, such as INT8 or timestamp, is LOWERING_SINK_UNSERVED); sort keys DECIMAL, DATE, FLOAT32 refused. Closest: src/op_agg_state, src/op_agg_hash, src/op_sort. Why: Float columns, date and decimal group/sort keys are ordinary in DataFrames and TPC-H (q3 order by date, q10, q13).
- **In-memory tables from Python** (task `pysdk-engine-inmem-table`). Earlier files: komira_engine_dispatch/inmem_leaf.mojo, komira_engine_dispatch/arrow_ipc_typed_source.mojo. Missing: Register an Arrow/pandas table with the context and run SQL on it; run_sql refuses plans with SOURCE_BATCH today (EXECUTE_UNSUPPORTED_PARAM) although cut_walk and BatchSource support it. Closest: src/scan_source/in_memory_source.mojo, src/sdk_exec/engine_catalog.mojo. Why: DataFrame and SQL over Python-held data is the SDK core use case.
- **Local Parquet write** (task `pysdk-engine-write-parquet`). Earlier files: komira_engine_dispatch/parquet_helpers.mojo. Served: COPY ... TO a local Parquet file through run_sql (src/sdk_exec/engine_write.mojo). Missing: to_parquet, CREATE TABLE AS (refused) and a streaming write sink in pipeline_exec. Closest: src/parquet_writer, src/sdk_exec/sink_variant_tags.mojo. Why: Writing query results to Parquet is a stated SDK need.
