# The package names claimed on the prod registry: one per line, sorted.
#
# release.yml publishes every member of the release (each src/<name> with a mopm.toml,
# //release/readme_e2e:packages.bzl) to the prod registry on every push to main, and the
# registry creates a package name only for its claimed owner. A member whose name is not
# claimed there makes `prod-stage` refuse and turns main red. The pull request check cannot
# write to the live registry, so it holds the members to this file instead
# (//release:prod_claimed_names_cases): a maintainer adds a name here only AFTER claiming it
# on the prod registry, in the pull request that adds the member or ahead of it. A name claimed
# for a library that is not published yet (its row in release/UNPUBLISHED.md) is listed too, and
# the check accepts a name no member has.
#
# A line stays when its package leaves the release: the 16 kci_* names (kci is retired and its
# libraries are deleted) stay reserved so nobody else can take them. They were published before
# the packages moved to the komira-ai namespace and are not in it: on prod each is a global (flat)
# name, `kci_<name>`, which the prune of the flat names kept, and there is no komira-ai/kci_<name>.
# The check refuses a dropped line of that set, and a member whose name is not claimed.
